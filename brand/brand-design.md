# Loop — 品牌设计理念

## 一、名称：Loop

**字面**：循环、闭环。

**为什么是 Loop**：

这个名字同时锚定了产品的三层叙事。

**第一层：方法论**。GTD 的原典概念就是 "open loop"——David Allen 把所有未完成的事都称作大脑里的开放循环，方法论的目标是关闭它们。Loop 这个名字直接对接 GTD 的母语。

**第二层：技术**。AI agent 的本质就是 loop——感知、推理、行动、再感知。一个 AI native 的 todo app，底层运行的就是一个 agent loop，帮用户持续观察、整理、推进任务。

**第三层：哲学**。人生本身是 loop——每天、每周、每季度、每年的循环。OS 是 loop，agent 是 loop，人生更是 loop。产品名说出了这件事，而不是回避它。

一个名字能承载这三层而不显得勉强，是因为它本身足够短、足够基础。Loop 不是隐喻，是事实。

## 二、Logo 设计理念

### 核心母题：一个未闭合的圆 + 一个橙点

整个 logo 只有两个元素，但它们在讲一个完整的故事。

**圆环**代表循环、系统、轨道——产品要承载的那个 loop。

**缺口**代表"还没完成"——这是 GTD 里的 open loop，是 todo app 存在的全部理由。如果所有事都完成了，app 就不需要了。

**橙点**代表"下一步行动"（next action）——GTD 方法论里最重要的概念。它停在缺口的起点，等着被滑过去、把循环闭合。

### 张力：名字是闭的，logo 是开的

这是整个设计的核心张力。

产品叫 Loop（闭合的理想状态），但 logo 画的是一个**没闭合**的 loop（未完成的现实）。中间那段缺口，就是 AI 要做的工作——帮你把开的变成闭的。

每次用户看到这个 logo，潜意识里都会想"补完它"。这正是产品想让用户感受到的动作。

### 颜色：克制的温度

- **近黑 #1A1A1A**：保持极简和高级感，避开科技公司扎堆的蓝紫色
- **珊瑚橙 #FF5C39**：一点暖色做点睛。todo app 是日常陪伴工具，不能冷
- **暖白 #FAFAF7**：app icon 背景，比纯白有质感

橙点是整个 logo 唯一的色彩。它是焦点、是行动、是"现在该做的那一件事"——和产品哲学一致：**不是给你看所有任务，是告诉你下一步**。

### 几何：可被精确复现

圆环半径 28、描边 10、缺口 90°、橙点半径 7——全部是整数。这不是审美洁癖,是为了让 logo 可以被精确缩放、做成动效、烧进各种尺寸而不变形。一个 AI native 产品的 logo，自己应该是参数化的。

### 隐藏的呼应

图标的缺口方向（12 点 → 9 点）和字母 **L** 的形状呼应——L 本身也是一个没闭合的形状。整个 logo 在不同尺度上讲同一件事："还没合上的循环，等着被关闭。"

---

## 三、一句话总结

> **Loop 是一个未闭合的圆，等着一个橙点把它合上。**
> 那个橙点是 AI，是下一步行动，是你。
